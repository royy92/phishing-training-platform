# Security Policy

## Reporting a Vulnerability

The security of the Phishing Awareness Training Platform is important to us.

If you discover a security vulnerability, please report it privately by email instead of opening a public GitHub Issue.

**Security Contact:**

[pat.platform3@gmail.com](mailto:pat.platform3@gmail.com)

## What to Include in Your Report

Please include the following information whenever possible:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential security impact.
- A proof of concept (PoC), screenshots, logs, or any other information that may help us understand the issue.

## Our Response Process

After receiving your report, we will:

- Acknowledge receipt of your report as soon as possible.
- Verify the reported issue and assess its severity.
- Work on an appropriate fix if the vulnerability is confirmed.
- Keep the report confidential until a fix has been released whenever possible.

Thank you for helping make the Phishing Awareness Training Platform more secure.
